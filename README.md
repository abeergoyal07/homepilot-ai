
# 🏠 HomePilot AI

**One request. Multiple actions. A smarter home.**

HomePilot AI is a smart-home automation prototype that demonstrates how AI-compatible tools can coordinate everyday home routines.

## ✨ Features

- Check the status of simulated smart-home devices
- Turn supported devices on or off
- Execute a predefined bedtime routine
- Receive structured reports of device states
- Expose automation tools through the Model Context Protocol (MCP)

## 🛠️ Built With

- TypeScript
- Node.js
- Express
- Model Context Protocol (MCP)
- Zod

## 🚀 Getting Started

### Requirements
Install Node.js 22 or a compatible supported version.

### Installation

```bash
npm install
npm run dev
```

Open http://localhost:3000 to see the server status.

## 🧪 Current Prototype

HomePilot AI currently uses simulated devices.
It does not control physical smart-home devices yet.
